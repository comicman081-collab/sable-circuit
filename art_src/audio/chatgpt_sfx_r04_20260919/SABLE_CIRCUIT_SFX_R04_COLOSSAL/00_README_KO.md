# SABLE CIRCUIT — R04 COLOSSAL

## 먼저 듣기
- `previews/BOSS_BLAST_R04_7s.mp3`: 영상에서 쓰는 v02 스테레오 폭발을 단독으로 재생합니다. 0.25초 후 시작합니다.
- `previews/COMBAT_R04_COLOSSAL_17s.mp3`: 전투 10초와 폭발 잔향을 포함합니다.
- `previews/R03_THEN_R04_EQUAL_PEAK_AB_12s.mp3`: R03(0.25초) → R04(4.5초). 피크만 같게 맞춘 비교이며, 평균 음량은 같지 않습니다.
- `previews/BOSS_SCALE_REEL_R04_20s.mp3`: 스킬 폭발 → 중량 착지 → 붕괴 순서입니다.

## 변경 범위
기본 게임 뱅크는 `audio/wav` 아래 48 kHz / 24-bit PCM / 모노 WAV 120개입니다.
보스 스킬 폭발(boss_cross_beam), 착지(boss_stomp), 붕괴(boss_destroy) 각 4개,
총 12개를 다시 만들었습니다. 나머지 108개는 R03와 바이트가 같습니다.
파일 경로 및 SC_R01 접두사는 기존 연결을 위해 유지합니다. 실제 뱅크 버전은 R04입니다.
별도로 `extras/stereo_boss`에 수정된 보스 효과 12개의 스테레오 대안이 있습니다.
이는 추가 12종의 새로운 이벤트가 아니라 같은 이벤트의 공간감 대안입니다.
`history`의 WAV는 R03 비교 자료이며, 게임용 120개에 포함하지 않습니다.

## 사운드 수정
짧고 날카로운 첫 파열음에 치우친 구성을 줄이고, 두꺼운 폭발 본체와
낮게 구르는 후속 울림이 지속되도록 기존 라이선스 소스를 새로 레이어링했습니다.
스킬 폭발은 6.4초, 착지는 4.0초, 붕괴는 7.0초입니다. 끝부분은 감쇠하는 잔향입니다.
전자식 상승 충전음, 레이저 발진기, 작은 금속 클릭을 새 폭발 레이어에 넣지 않았습니다.
기존 4개 charge 파일은 수정하지 않았습니다.
신규 실녹음이나 새로 다운로드한 대형 폭발 녹음이 아니라, 포함된 폭발 원재료와
신규 신호 처리를 이용한 사운드 디자인입니다. 청감 적합도는 사용자 검토 대기입니다.

## 영상/믹스
원본 전투는 1920×1080, 60fps, 600프레임, 10초입니다.
직접 프레임을 비교하면 흰색 교차 공격은 582번 프레임(0부터 계산), 9.70초에 시작합니다.
이전의 폭발 시점 9.56초에서 9.70초로 0.14초 이동했습니다. 나머지 이벤트 시점은 그대로입니다.
전체 마스터 게인은 이전과 같습니다. 마지막 폭발 순간에만 다른 효과음 버스를
최대 8 dB 낮췄습니다(9.66초 시작 → 9.70초 최대 → 10.12초까지 유지 → 11.0초 복귀).
영상용 폭발은 v02 스테레오 대안을 사용하며, 방 잔향을 중복으로 추가하지 않습니다.
17초 영상은 원래 전투 10초 + 마지막 프레임 7초 유지입니다. 추가 전투가 아닙니다.
10초 영상은 원본 비디오 스트림을 복사하며 오디오만 교체합니다. 폭발의 꼬리는 길이상 잘립니다.
17초 영상은 프레임 유지를 위해 재인코딩합니다. 첫 10초도 압축 픽셀이 완전히 같다는 뜻은 아닙니다.
이 결과는 후시 제작 예시입니다. 게임 이벤트 연결이나 엔진 통합 테스트는 수행하지 않았습니다.

## 게임 적용
기본 교체는 기존과 같은 상대 경로의 `audio/wav` 파일을 사용합니다.
보스 폭발의 공간감을 직접 쓰려면 `extras/stereo_boss`를 별도로 연결합니다.
모노와 스테레오 파일을 동시에 틀지 마세요. 공격 애니메이션이 끝났다고 잔향을 끊지 마세요.
동일 효과를 매 프레임 재생하지 말고 발동 이벤트에서 한 번 재생합니다.
믹스의 8 dB 일시 감쇠는 이 미리듣기 설정이며 자동으로 게임에 적용되지는 않습니다.

## 재생성
Python + NumPy + SciPy + soundfile, 시스템 FFmpeg가 필요합니다.
`python tools/build_r04.py`는 12개 보스 모노 파일과 12개 스테레오 대안만 재생성합니다.
`python tools/render_r04.py`는 오디오 미리듣기를 생성합니다.
`bash tools/render_video_r04.sh /path/to/sable_in_app_combat_10s.mp4 /output/path`는 영상을 생성합니다.
`python tools/validate_r04.py --video-dir /output/path --original-video /path/to/sable_in_app_combat_10s.mp4`
로 파일 규격/이전 파일 보존/디코딩/추정 피크/재현성을 검사할 수 있습니다.
기술 검사 결과는 음색이 사용자 취향에 맞는다는 판정이 아닙니다.
