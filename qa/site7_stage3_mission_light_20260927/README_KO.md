# SITE-7 작전 3–5 작전별 방 조명 (2026-09-27)

## 요청

사용자 지시: 스테이지가 반복되는 느낌이 들지 않게 하고, 조명·채도·명도·스타일을 작전마다 구분한다.

Codex 단계 3(커밋 `4c4dca0f4`) 뒤에는 작전 3·4·5가 같은 v2 방 판 8장을 쓴다. 판별 무드 행도 판 하나에 하나뿐이었다. 그래서 같은 판 위의 방은 작전 행의 색만 달랐다. 작전 3과 4는 둘 다 붉은·호박 톤이라 거의 같아 보였다(01, 02).

## 구현

- **작전별 판 행**: `data/visual/site7_mood.json`의 작전 행에 `"plates"`를 둔다.
  - 공유 판 행 위에 키 단위로 덮어쓴다. `lights`는 목록 전체를 바꾼다.
  - `scripts/missions/site7_mood.gd`의 판 조회는 모두 작전 id를 받는다. `site7_room_art_layer.gd`가 선택된 작전을 넘긴다.
- **도구**: `tools/environment/build_site7_mood_light.py`는 공유 목록에 없는 판을 가리키는 작전 행을 거부한다. 작전 행에만 `lamps`가 있어도 조명 웅덩이를 찾는다.
- **테스트**: `tests/smoke/site7_battle_geometry_smoke.gd`가 여러 작전이 함께 쓰는 판을 검사한다. 두 작전에서 방 등급 차이가 0.05 미만이거나 조명·채움이 같으면 FAIL이다(판 8장 × 짝 3 = 24개 검사).
  - 음성 확인: 작전 행 `plates`를 메모리에서 지우고 같은 비교를 돌리면 24쌍이 모두 걸린다(`capture_scripts/negative_shared_light.gd`, `flagged 24 of 24`).
