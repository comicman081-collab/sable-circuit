확인:

```
python qa/site7_op10_art_approval_20261002/tools/verify_hashes.py
```

17개가 모두 같으면 `17 of 17 approved files unchanged`를 찍고 0으로 끝난다. 다르면 `CHANGED`나 `MISSING`과 파일 이름을 찍고 1로
끝난다(게임 오류가 아니라 "새 그림"이라는 뜻이다). 파일은 읽기만 한다.
