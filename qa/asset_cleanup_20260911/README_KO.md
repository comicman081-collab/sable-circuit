## 증거 및 복구 범위

- `retirement_manifest.json`: 삭제한 모든 파일의 원래 경로·크기·SHA-256.
- `protected_before.json`: 보존 파일의 사전 해시.
- `quarantined_verification.json`: 격리 파일의 정확한 일치 검증.
- `runtime_validation.json`: 실제 앱/에셋 검사 결과 및 로그 경로.
- `purged_verification.json`: 삭제 대상 부재, 격리 payload 부재, 보존 파일 불변 확인.
- 과거 거절 이력과 해시 블랙리스트는 그대로 남겼다.

격리 payload는 휴지통 이동이 아닌 영구 삭제했으며, 이 정리 작업은 파일
백업을 남기지 않았다. 삭제 목록과 해시는 파일 내용의 복구본이 아니다.
일부 기존 Git 추적 파일은 저장소 이력에 남아 있을 수 있다.

완료 판정은 `purged_verification.json`을 따른다. `audit_summary.json`과
`seal.json`의 과거 상태는 작업 전 시점의 기록이므로 덮어쓰지 않았다.
