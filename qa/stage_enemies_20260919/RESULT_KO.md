## 원화와 실제 연결

내장 ImageGen으로 제작한 두 이동형의 8방향씩과 고정 포격기 1장을 사용한다.
프로젝트 원본은 `motion_lab_v1/art/stage_enemies_20260919/`, 요청·실제 반환
정보·알파 검사·현재 선택은 같은 이름의 Motion Studio QA 디렉터리에 보존했다.
생성된 RGBA 배경 0 / 피사체 1..254를 그대로 사용하며 크로마 제거·알파 강제
보정·좌우 반전·평면 회전으로 방향을 만들지 않았다. 내보내기는 무손실 크롭이다.

프로젝트 원본 21개와 해시가 동일한 Codex 임시 생성 폴더의 중복 PNG 21개만
정리했다. 프로젝트 원본·이전 후보·실패 기록은 전부 보존했다. 삭제한 중복본은
프로젝트 원본에서 복원 가능하며 정확한 경로·해시는 `staging_retirement.json`에 있다.

실제 등록은 `data/art_profiles/enemy_profiles.json`이고 배포용 파일은
`assets/enemies/bulwark/authored_yaw8_v1`, `cinder_ram/authored_yaw8_v1`,
`vesper_mortar/authored_core_v1`에 있다. 앱은 QA 후보 파일을 읽지 않는다.
추가된 종류를 스테이지별 기존 적과 섞었으며 전체 처치 수 10 / 7 / 7과
개별 체력·보상을 유지했다. 3스테이지 포격기는 이동 드론용 사각에 고정되지
않도록 돌진기와 스폰 순서를 교체했다. 엄폐물을 지우거나 축소하지 않았다.

강제 방 진행은 사용하지 않았다. 기존 플레이어 입력 코드는 바꾸지 않았다.

## 범위

네이티브 화면은 제어된 연습전 장면이고 전체 경로는 자동 테스트 입력이다.
사람 플레이테스트, 전 게임 완성, 외부 GPT 검토, Luna 재현 또는 원격 배포를
주장하지 않는다. 전술 시간 간격 검사는 30/60/120이며 충돌·포탄 실검사는
60Hz다. 다른 프로젝트 이미지·모델·잠긴 제작 도구는 사용하지 않았다.

Studio 적 제작 지침에는 새 5종 로스터와 고정 적의 접근/사선 검사를 반영했다.
스킬 문법 검사는 통과했으며 이것을 새 모델의 재현 성공으로 확대하지 않는다.
