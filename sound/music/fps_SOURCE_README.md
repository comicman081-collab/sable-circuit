# First-Person Shooter Original Audio Pack

FPS 게임 전용 오리지널 오디오 패키지입니다. **타이틀곡 10곡, 인스트루멘털 BGM 100곡, 영어 보컬 엔딩곡 10곡**으로 총 120곡을 수록했습니다. 분대 전술, 침투, 점령, 호송, 저격, 폭탄 해체, 최종 작전과 임무 이후의 귀환을 중심으로 구성했습니다.

| 폴더 | 수량 | 내용 |
|---|---:|---|
| `01_title_songs` | 10 | 영어 보컬 타이틀곡, 전투 개시·분대·돌파·최종 방어를 표현하는 메인 테마 |
| `02_bgm` | 100 | 훈련장, 폐허 도시, 점령전, 해체 작전, 호송, 저격, 지하철, 공군기지, 항구 방어용 인스트루멘털 |
