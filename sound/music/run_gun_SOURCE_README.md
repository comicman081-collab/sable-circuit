# Run and Gun Original Audio Pack

런앤건 장르 게임을 위해 제작한 **오리지널 고에너지 오디오 에셋 100종**입니다. 모든 음악과 가사는 기존 작품을 모방하지 않는 독창적 구성으로 제작했으며, 게임 플레이에서 바로 사용할 수 있도록 카테고리별 폴더로 정리했습니다.

## 구성

| 폴더 | 수량 | 설명 |
|---|---:|---|
| `01_title_songs` | 10 | 런앤건 타이틀 및 오프닝 테마. 영어 보컬곡과 인스트루멘털 테마 포함 |
| `02_bgm` | 50 | 전투·추격·침투·탈출 상황용 고에너지 BGM |
| `03_button_clicks` | 10 | 메뉴 이동, 무기 선택, 임무 수락 등 UI 버튼음 |
| `04_event_music` | 20 | 보스 경고, 목표 갱신, 매복, 보급품 발견 등 이벤트 큐 |
| `05_ending_songs` | 10 | 전투 종료와 생존·승리를 주제로 한 영어 보컬 엔딩곡 |

## 오디오 사양

음악 파일은 MP3 형식이며, 고음질 인코딩을 적용했습니다. 버튼 클릭음은 약 1초, 이벤트 음악은 최대 약 12초로 정리하고 짧은 페이드 인·아웃을 적용했습니다. BGM은 플레이 중 반복 사용하기 쉽도록 대부분의 트랙을 루프 지향 구조로 제작했습니다.

## 파일명과 사용 권장

파일명은 영문 소문자와 언더스코어로 구성되어 게임 프로젝트에 쉽게 연결할 수 있습니다. `title_songs`와 `ending_songs`는 메뉴·인트로·결과 화면에, `bgm`은 스테이지별 전투 상황에, `button_clicks`와 `event_music`은 UI 및 게임 이벤트에 사용하는 것을 권장합니다.

## 검증

총 파일 수는 **100개**입니다. 카테고리별 수량은 타이틀 10개, BGM 50개, 버튼 클릭음 10개, 이벤트 음악 20개, 엔딩곡 10개입니다. 모든 MP3 파일은 `ffprobe`로 파일 무결성과 재생 시간 확인을 완료했습니다.

## 저작권 안내

본 패키지의 음원과 가사는 이 작업을 위해 새로 생성된 오리지널 콘텐츠입니다. 기존 아티스트, 곡명, 프랜차이즈의 멜로디나 가사를 재현하도록 요청하지 않았으며, 실제 상용 게임에 적용하기 전에는 프로젝트의 최종 라이선스·배포 조건을 별도로 확인하시기 바랍니다.
