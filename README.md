# SABLE CIRCUIT — 웹 실행본 / playable web build

**플레이 / Play: https://comicman081-collab.github.io/sable-circuit/**

SABLE CIRCUIT 의 브라우저용 실행본입니다. 이 브랜치(web-build)에는 빌드된 게임 파일만 있고, 게임 소스는 저장소의 기본 브랜치에 있습니다.
This branch (web-build) holds only the built game (Godot 4.7.1 Web export, single thread); the game's source is on the repository's default branch.

- 1장 SITE-7: 작전 10개, 조종 가능 대원 3명, 보스 10종 / Chapter 01, 10 operations, three operators, 10 bosses.
- 데스크톱 브라우저(Chrome, Edge, Firefox) + 키보드·마우스 권장. 휴대폰은 검증하지 않았습니다 / Desktop browser with keyboard and mouse recommended; phones are untested.
- 처음 한 번 약 244 MiB 를 내려받습니다(그림·음악 포함). 이후에는 브라우저가 보관합니다 / The first load downloads about 244 MiB (art and music); the browser keeps it afterwards.
- 진행 상황은 이 브라우저 안(IndexedDB)에만 저장됩니다. 계정 저장이 아니며, 사이트 데이터를 지우면 사라집니다 / Progress is saved in this browser only (IndexedDB), not in an account; clearing site data removes it.
- 시험용 빌드입니다. 균형과 플레이는 아직 사람이 검증하지 않았습니다 / A test build: balance and play have not been checked by a person yet.
- 크레딧은 게임 타이틀 화면에 있습니다 / Credits are on the game's title screen.

Built 2026-10-08 from the author's local commit 480c5bee.
