# SABLE CIRCUIT Web Demo

The Sites checkout is `web_demo`; it is a separate Git repository so deployment
does not push the game workspace, QA media, original tools, or unrelated history.
Reuse `web_demo/.openai/hosting.json` and its existing Site ID on every update.

`tools/environment/build_sites_demo.py` stages the current Godot application,
uses the installed Godot 4.7.1 non-threaded Web export template, preserves raw
PNG/WebP/JSON data needed by the runtime loaders, and exports the playable demo.
The original art, sound and intro sources remain unchanged. Superseded
`assets/units` fallback data and read-only external models are not web payloads.

Delivery shards are at most 20 MiB. `chunk-loader.js` verifies each shard's
SHA-256 and reconstructs the exact PCK/WASM byte streams. This is a lossless
transport adaptation, not image resampling. The initial game download is about
250 MB before HTTP compression. Device-local save state uses browser IndexedDB;
it is not a cloud account save and clearing site data removes it.

The first monolithic source push hit HTTP 413. For this new empty Site only,
`push_sites_incremental.py` uploads bounded Git packs, retains the local
pre-upload branch, and verifies that the final uploaded tree matches the
validated delivery tree. Credentials are stdin-only/per-command, never saved.
Its ignored receipt allows resumption after credential expiry. Do not use it to
overwrite an existing remote branch or restart Site creation.

Sites rejected the 454 MB archive because its input limit is 256 MiB. The final
217 MB archive uses 90 WebP background-plate derivatives at the original pixel
dimensions and quality 95. Every alpha channel is byte-identical to its PNG
master. No actor, enemy, cover collision mask, sound or movie is recompressed.
Exact bindings and measured PSNR (minimum 37.45 dB) are in
`qa/demo_web_20260920/web_plate_derivatives.json`; visual review is separate.
`BattleTextureLibrary.has_texture` and `texture` resolve the same WebP alternative
only on Web; the native game keeps original PNG loading.

The installed Sites helper cache disappeared during this task after earlier
successful official packaging. `package_sites_static.py` is the scoped fallback:
it verifies the previous official archive's manifest contract, validates all
delivery chunk hashes, packages only dist plus hosting metadata, and enforces
both the 256 MiB archive limit and 25 MiB individual-file ceiling.

The user explicitly chose public, anyone-with-the-link access on 2026-09-20.
Local browser review and native 1080p evidence are in `qa/demo_web_20260920`.
Physical mobile multitouch and a complete browser campaign playthrough remain
unverified; do not relabel these checks as complete gameplay/art approval.
